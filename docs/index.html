Everything You Expect in a Pro GIF Tool

Zero compromises on quality, file weight, or capture ergonomics.

ScreenCaptureKit 60 FPS & Isolation

Native Apple hardware-accelerated capture pipeline on macOS 12.3+ for silky 60 FPS recording with lower battery drain. True window isolation captures your target window even when covered or moved.

Multi-Format Export (WebP & MP4)

Export in modern animated WebP for tiny byte sizes or lightweight H.264 MP4 for instant video embedding alongside crisp, high-compatibility GIFs.

4x Pixel Loupe Magnifier

Real-time circular zoom lens under the cursor with crosshairs and coordinate readouts while dragging or resizing region edges for pixel-perfect window alignment.

Annotations & Privacy Redact

Add directional arrows, text captions, and mosaic blur boxes to obscure passwords, API keys, or private tokens directly in the review editor before saving.

Bayer 4×4 Spatial Dithering

Advanced palette quantization preserves silky smooth gradients without the noisy snow or ballooning byte sizes typical of error diffusion algorithms.

Cursor Spotlight & Click Ripples

Never lose the mouse again. Enjoy customizable spotlight halos, distinct cursor tracking, and expanding animated ripple rings on mouse clicks.

Post-Recording Trim & Review

Scrub through recorded frames, dial in precise In/Out trim markers, and inspect the loop before saving to disk. Perfect loops every time.

Native Drag & Drop & CLI Headless

Drag recordings straight into Slack, Discord, Finder, or Google Chrome. Or trigger automated headless recordings from CI and terminals with gifkite record.

Build & CLI Documentation

Simple to compile, easy to integrate into CI/CD pipelines.

Terminal — Multi-Platform Build with Taskfile 
# macOS — Build and launch local app bundle
task dev

# Windows — Cross-compile standalone gifkite.exe with embedded icon
task build:windows

# Linux — Build native binary (requires GTK3 / WebKitGTK dev headers)
task build:linux
Terminal — Headless CLI Recording 
# Record 10 seconds of a specific screen region with full effects
./gifkite record -region 100,100,800,600 -duration 10s -dither bayer -cursor -highlight -ripples -o demo.gif

# Inspect available displays and pixel bounds
./gifkite displays
