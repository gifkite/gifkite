Window Snapping & Multi-Display

Snap precisely to any background or foreground application window with one click, drag custom coordinates, or record seamlessly across multi-monitor Retina displays.

Bayer 4×4 Spatial Dithering

Advanced palette quantization preserves silky smooth gradients without the noisy snow or ballooning byte sizes typical of error diffusion algorithms.

Cursor Tracking & Click Ripples

Never lose the mouse again. Enjoy customizable spotlight halos, distinct cursor tracking, and expanding animated ripple rings on mouse clicks.

Post-Recording Trim & Review

Scrub through recorded frames, dial in precise In/Out trim markers, and inspect the loop before saving to disk. Perfect loops every time.

Native Drag & Drop Sharing

Drag any GIF thumbnail directly out of the popover and drop it straight into Slack, Discord, Messages, Finder, or Google Chrome with native Cocoa NSDraggingSession.

Menu Bar First & CLI Headless

Build & CLI Documentation

Simple to compile, easy to integrate into CI/CD pipelines.

Terminal — Build from Source (macOS) 
# 1. Clone repository
git clone https://github.com/gifkite/gifkite.git
cd gifkite

# 2. Compile native binary and package Gifkite.app
./build-app.sh

# 3. Launch application
open Gifkite.app
Terminal — Headless CLI Recording 
# Record 10 seconds of a specific screen region with full effects
./gifkite record -region 100,100,800,600 -duration 10s -dither bayer -cursor -highlight -ripples -o demo.gif

# Inspect available displays and pixel bounds
./gifkite displays
