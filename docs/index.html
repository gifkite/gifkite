Everything You Expect in a Pro Screen Recorder

Zero compromises on quality, file weight, or capture ergonomics.

ScreenCaptureKit 60 FPS & Isolation

Native Apple hardware-accelerated capture pipeline on macOS 12.3+ for silky 60 FPS recording with lower battery drain. True window isolation captures your target window even when covered or moved across spaces.

Multi-Format Export (WebP, MP4, GIF)

Export in modern animated WebP for up to 42% smaller file sizes, lightweight H.264 MP4 for instant browser and chat playback, or crisp Bayer-quantized GIFs with universal compatibility.

4x Pixel Loupe Magnifier

Real-time circular zoom lens under the cursor with pixel crosshair and coordinate badge while dragging or adjusting selection handles for pixel-perfect edge alignment.

Interactive Picker & Window Snapping

Hover over any application window to highlight and snap to its exact frame. Drag 8 resize handles with aspect ratio presets (16:9, 4:3, 1:1, Free) and live dimension inputs.

Annotations & Undo / Redo

Add directional callout arrows, custom text captions, and mosaic privacy blur boxes with complete multi-level Undo & Redo (⌘Z / ⇧⌘Z) history to protect sensitive API keys, tokens, and passwords.

Editor Studio: Trim & Canvas Crop

Scrub frame-by-frame with interactive dual In/Out trim markers, drag interactive crop handles on the canvas to isolate any sub-area, and preview loop speed (1x, 1.5x, 2x) before exporting.

Direct 1-Click Save or Edit Later

Record and immediately save directly into your preferred format without mandatory review delays. Your recordings stay in the spacious Popover Library ready to be reopened in the Editor Studio anytime.

Bayer 4×4 Spatial Dithering

Advanced palette quantization preserves silky smooth gradients without the noisy snow or ballooning byte sizes typical of error diffusion algorithms.

Cursor Spotlight & Click Ripples

Never lose the mouse again. Enjoy customizable spotlight halos, distinct cursor tracking, and expanding animated ripple rings on mouse clicks.

App Invisibility & Zero Clutter

Gifkite's floating recording pill, picker, and overlay controls are automatically excluded from the recording frames using OS-level capture sharing affinity, ensuring spotless recordings.

System Tray & Headless CLI

Click the tray icon to drag recordings straight into Slack, Discord, or Finder. Or trigger automated headless recordings from CI and scripts with gifkite record.

Build & CLI Documentation

Simple to compile, easy to integrate into CI/CD pipelines and headless environments.

Terminal — Multi-Platform Build with Taskfile 
# macOS — Build and launch local app bundle
task dev

# Windows — Cross-compile standalone gifkite.exe with embedded icon
task build:windows

# Linux — Build native binary (requires GTK3 / WebKitGTK dev headers)
task build:linux
Terminal — Headless Multi-Format Recording CLI 
# Record 10s region to animated WebP with Bayer dithering
./gifkite record -format webp -region 100,100,800,600 -duration 10s -dither bayer -cursor -highlight -ripples -o demo.webp

# Record full screen to lightweight H.264 MP4 video
./gifkite record -format mp4 -duration 15s -o screen-record.mp4

# Inspect available displays and pixel bounds
./gifkite displays
Terminal — macOS Gatekeeper First-Run Helper 
# If macOS displays "Apple could not verify Gifkite is free of malware":
xattr -cr /Applications/Gifkite.app

# Or double-click the bundled "Open Gifkite (First Run).command" inside the DMG
